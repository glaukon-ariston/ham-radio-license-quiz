# P1-0056 — Rewrite git history to strip docs/ from all commits before any public push

## What was done

1. **Backup first.** Before touching anything, created a full backup of every ref via
   `git bundle create <scratchpad>/pre-filter-repo-backup.bundle --all` (73 MB, contains both
   `main` and `queue-drain` with their pre-rewrite history). Kept outside the repo in the
   session scratchpad, not staged/committed.

2. **Confirmed the precondition from the item file**: `git remote -v` printed nothing before
   starting — this repo has never been pushed anywhere, so a history rewrite is safe and
   won't orphan a remote.

3. **Installed `git-filter-repo`**: `pip install git-filter-repo` (v2.47.0; not previously
   installed). Confirmed callable via `git filter-repo --version`.

4. **Ran the rewrite exactly as specified in the item's Method**:
   `git filter-repo --path docs --invert-paths --force`
   (`--force` was required because this isn't a fresh clone — git-filter-repo refuses to run
   on a repo with existing history/state otherwise; nothing else about the command changed).
   Processed 92 commits, completed in ~5s, then repacked/cleaned automatically.

5. **Ran `git gc --aggressive --prune=now`** afterward to force-expire the reflog and purge
   now-unreachable `docs/` blobs from the pack immediately rather than waiting on gc's default
   grace period.

  `docs/` path.
- `git rev-list --objects --all | grep docs/` → **empty**. No blob under `docs/` exists in the
  object store at all, on any ref.
- **Both branches still exist** with commit counts unchanged from before the rewrite:
  `main` = 10 commits (was 10), `queue-drain` = 92 commits (was 92). Spot-checked `git log
  main --oneline` and `git log queue-drain --oneline` — non-`docs/` commit messages and order
  are intact (e.g. `main`'s `Initial commit: A-class quiz corpus...` through
  `Replace remaining name references...` all present, just under new hashes as expected since
  filter-repo rewrites every commit that follows a changed one).
- **Working tree `docs/` untouched**: `ls docs/` still shows all 21 files present on disk
  (this was never in git's index to begin with — P1-0055 untracked it earlier in this drain
  run — filter-repo only touched history, never the working tree).
- **No remote added, nothing pushed**: `git remote -v` still empty after the rewrite.
- **Repo hygiene**: `.git` shrank from 70 MB to 1.2 MB (the ~130 MB of PDF blobs, mostly
  already partially packed, are gone from every pack). `git count-objects -v` shows 0 loose
  objects, 0 garbage. No `refs/original/*` backup refs left behind (git-filter-repo doesn't
  create them, unlike `git filter-branch`) and the reflog is empty — nothing to leak the old
