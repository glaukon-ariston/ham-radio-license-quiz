# P2-0049: fix bk-pra-3-02 fabricated callsign OCR-error claim

## What was wrong

`bk-pra-3-02`'s note quoted option b) of SKUPINA III. pit. 2 (tiskana str. 388) as
`"F5SBDW ? PSE UR CALL AGN de 9A$SJA + PSEK"` and attributed the garbling to "OCR knjige
[koja] unosi grafičke greške u pozivne oznake" (the book's own OCR introducing errors).
This was the third confirmed instance in this one file of the LARU/IARU-class bug: the
garbled string was PyMuPDF's own extraction artifact, mislabeled as a defect in the book.

## Recovery

Recovered `git stash@{2}` ("queue P3-0016: fail (repair attempt 3)"), confirmed via
`git stash show -u stash@{2} --stat` that it touches exactly
`quiz/build/notes_book_s3_pravila.json` and `queue/reports/P3-0016.md` (706 insertions,
matching the described round-3 repair). Applied with `git stash apply stash@{2}` (stash
left in the stash list, not dropped).

## Verification against a rendered page (not OCR text)

Used `booktool.py`'s `load('RK')` to resolve printed str. 388 -> pdf index 381, then
rendered that page (and a 600 dpi crop of question 2) with PyMuPDF's `get_pixmap` and read
the image directly. The book prints, cleanly, no garbling:

- Question stem: "Uz jake smetnje primili smo poziv radiopostaje **F5DBW** i ako nismo
  sigurni u ispravnost pozivne oznake, odgovorit ćemo:"
- a) F5BDW de 9A5JA – GD DR OM PSE RPT URT NAME + PSE K,
- b) **F5BDW ? PSE UR CALL AGN de 9A5JA + PSE K,**
- c) CQ CQ CQ de 9A5JA 9A5JA + PSE K,
- d) PSE QTH ES NAME AGN + PSE K.

This confirms the item's stated correction exactly. (Note in passing, not acted on: the
question stem itself reads "F5DBW" while both options a) and b) read "F5BDW" — a real
difference in the printed book between stem and options, not something introduced by any
extraction tool. Item did not ask to explain this, so the note was left to focus only on
decoding the abbreviations in option b), which is what makes b) correct regardless.)

## Fix applied

In `quiz/build/notes_book_s3_pravila.json`, `bk-pra-3-02.note`: replaced the garbled quote
and the false "OCR knjige" framing with the text read directly off the rendered page, and
reframed the citation as "pročitano izravno s renderirane slike stranice, ne iz
OCR/tekstualne ekstrakcije". Rest of the note (decoding PSE/UR/CALL/AGN, why b) is right,
why a/c/d are wrong) is unchanged — it still holds against the corrected text.
