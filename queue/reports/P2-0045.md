# P2-0045 — Add home button on every page

## What changed

`quiz/build/build_quiz.py` — the source that generates `quiz/quiz.html` (gitignored
deliverable, not touched directly; regenerated and inspected, same pattern as P1-0038 and
P2-0039).

**CSS.** Generalised the id-scoped `#qcrumb a{...}` breadcrumb-link style into a reusable
`.crumb a{...}` class rule, so the same visual treatment (accent colour, no underline until
hover/focus) can be applied to a home link wherever a breadcrumb does or doesn't already
exist, not just inside `#qcrumb`.

**Quiz screen (`#quiz`, covers practice / exam / wrong-review / single deep-link — the
"review" screen in the item is this same section with `mode==="wrong"`).** In `render()`,
prepended a `← Početna` anchor to the `#qcrumb` breadcrumb, before the section/cjelina links.
Unlike those links it is never turned into an inert `<span>` in exam mode — it stays clickable
so there's always an exit — but its `onclick` goes through a new shared `leaveQuiz()` helper
instead of navigating directly.

**`leaveQuiz()` (new function).** Factored out of the pre-existing `#quit` button's
`onclick`, which used to inline `askConfirm("Prekinuti i odbaciti ovaj pokušaj?", () =>
show("home"))` directly. Now both `#quit` and the new breadcrumb home link call
`leaveQuiz()`, so they are *guaranteed* identical, not just written to look the same:
```js
function leaveQuiz(){
  if(S && S.mode !== "single") askConfirm("Prekinuti i odbaciti ovaj pokušaj?", () => show("home"));
  else show("home");
}
```
This reuses the in-page `askConfirm()` overlay added by P1-0038 — never `window.confirm()`,
which is a silent no-op in the sandboxed iframe this page runs in on claude.ai. For
`mode==="single"` (a deep-linked question, no running attempt to lose) it skips the prompt,
matching `#quit`'s pre-existing behaviour of being hidden entirely in that mode.

**Picker screen (`#picker`, the practice-mode area/cjelina picker).** No breadcrumb existed
here at all. Added `<div class="eyebrow crumb"><a href="#" data-go="home">← Početna</a></div>`
at the top, above the `<h2>`. This is plain navigation with no confirm needed — nothing is
in progress yet on this screen. Left the pre-existing bottom `← Natrag` button (`data-go=
"home"`) alone; it predates this item, is a different element (a full `.btn`, not a
breadcrumb link) and isn't "competing" with anything, just a second point of the same
one-click action for a screen that can have a long scrollable list.

**Result screen (`#result`, shown after practice/exam finishes).** Same pattern: added the
identical top `eyebrow crumb` home link above `<h2 id="resTitle">`. Left the existing bottom
`Početna` primary-CTA button as-is — it's the natural next action after seeing a score, a
different role from the top wayfinding link.

**Home screen (`#home`) and "settings":** not touched. It already *is* the home screen, and
there is no separate settings page — the source/theme `<select>` controls live in the sticky
`header.bar`, which renders unchanged on every screen already, so nothing needed adding
there.
