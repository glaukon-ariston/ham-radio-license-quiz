## Method — full word-for-word verification, per the caller's brief

Given this series' history of citation defects (wrong article content, wrong page pointer,
note-vs-cite mismatch), every claim in every note was pulled and read directly from the source
PDF with `booktool.py` (and pymupdf rendering for table-image pages) before it went into a
note — never reused from the packet's own `current_cite` (which for all 40 ids is only
`"tablica ODGOVORI NA PITANJA"`, an answer-table pointer, not a content citation) or from its
`hrs_source` page numbers.

## Packet's `hrs_source` is off by exactly one page, same bug as S4/S5

`booktool.py find RK "SKUPINA VI."` shows two occurrences: pdf 366→printed 373 (the *technical*
exam, already covered by P3-0026/0027) and pdf 396→**printed 403** (the pravila exam this item
covers). The packet's `hrs_source` claims printed 402–407; the real pages, confirmed by reading
each one directly, are **403–408**:

- q1–6 → printed 403
- q7–14 → printed 404
- q15–22 → printed 405
- q23–30 → printed 406
- q31–38 → printed 407
- q39–40 → printed 408

All 40 questions' stems and all four options were compared word-for-word against these six
pages. Everything matched the packet exactly (this OCR is clean for pravila text — no
formulas/Greek letters to corrupt, unlike the tehnicki packets). Not fixed in the packet file
itself (out of this item's `files:`); every `cite` in the notes file uses the page verified
live, not the packet's claimed page.

`ODGOVORI NA PITANJA, C) HRVATSKA I MEĐUNARODNA DJELATNA PRAVILA I POSTUPCI` spans printed

## Sources used for supporting citations

Beyond the exam page itself, each note draws on the actual book passage that backs its claim,
verified by direct read:

- RK Q-kod (str. 251), operativne kratice (str. 252–255) — every abbreviation-decoding question
  (QTH, QSO, QSP, QRG, QAP, QRL, PSE, QSL, CALL/AGN/DE, IARU, NAME/RST, and the four
  message-decode questions built from TNX/FER/UFB/RPRT/HPE/CUAGN/VY/73/GE/DR/OM/ES).
- RK popis pozivnih oznaka / DXCC lista (str. 260–262, rendered — the OCR badly interleaves the
  two name/prefix columns) — confirmed CT4BB/Portugal, VK1SS/Australia, HASKDQ/Hungary,
  ZA2RIB/Albania, HGIDD/Hungary, OH1CC/Finland.
- RK plan pojaseva IARU-a (str. 264, 266) — 3,792 MHz telephony legality, the LSB(≤10 MHz)/
  USB(>10 MHz) rule (applied to both KV and, since it isn't exempted, UKV), and the "natjecanja
  se ne smiju odvijati u 10/18/24 MHz" note used to support "shortwave contests are allowed
  elsewhere."
- RK Plan VHF pojaseva (str. 268–270) — 144,300 MHz is explicitly labelled "SSB pozivna
  frekvencija" within the 144,150–144,400 telegraphy/SSB segment.
- RK 1.2 Definicija amaterske postaje (str. 210) — near-verbatim match for "što je
  radiopostaja" (q27).
- RK 4. Međunarodni znakovi za nesreće (str. 256) — MAYDAY.
- PZM Tema 23 Amaterske kratice (str. 139) — found the DX distance definition itself: "DX —
  Daleka veza: na KV-u preko 3000 km, na UKV-u preko 300 km," which is an exact numeric match
  for q1 and wasn't used in the S4/S5 pravila notes (a better source than anything found for
  the equivalent S4/S5 question, if there was one).
- PZM Tema 24 (str. 141, Zakon o telekomunikacijama čl. 65), Tema 26 Pregled raspodjele
  amaterskih frekvencija (str. 143–144, incl. the explicit "144-145 MHz horizontalna; 145-146 —
  vertikalna" polarization line used for q20, and the VHF/UHF allocation table used to rule out
  174,000 MHz for q28), Tema 29 ITU regije (str. 148, "u prvom su području Afrika, Europa,

  tzv. Call-book"), Tema 33 kodeks ponašanja (str. 155, reused verbatim from S5-19 since q19 is

## Honest caveats recorded in specific notes (not overclaimed)

- **q12** (sustav lokatora): PZM's WW-lokator section primarily describes it as a way to *mark
  geographic position*, not "a system for determining distance between stations." The note
  quotes that primary definition and separately notes that conversion software derived from it
  can print distance (QRB) — the closest available reading to HRS's own option (c), stated
  transparently rather than silently treating the paraphrase as a direct definition.
- **q18** (UTC/winter log time): NN150/22 requires the log in UTC, which is cited directly. The
  arithmetic step (Croatia's winter civil time is UTC+1) is **not** stated verbatim anywhere in
  RK or PZM — the note says so explicitly and presents it as a `formula`, not a citation.
- **q7, q8**: no additional citation beyond the exam page — searched RK and PZM for the general
  purpose of abbreviations (q7) and a formal definition of "telekomunikacije" (q8) and found
  neither stated in so many words, so cited nothing per the Avoid clause (same outcome as the
  equivalent question in S5).
