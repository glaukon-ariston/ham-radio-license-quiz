# P3-0027 — Book notes, skupina VI tehnički, paket _b

## Scope

Wrote `quiz/build/notes_book_s6_tehnicki_b.json`: one teaching note per id in
`quiz/build/work/packet_book_s6_tehnicki_b.json` (30 ids, `bk-teh-6-02` through `bk-teh-6-60`,
even numbers only — the `_b` half of skupina VI's technical exam, completing skupina VI
alongside `notes_book_s6_tehnicki_a.json` from P3-0026). Same `{note, formula?, cite}` shape
as every prior book-notes file. No `links` key — matches the established convention that
`link_check.py`/`check_notes.py` only glob `notes_zzz_expanded_*`. `packet_book_s6_tehnicki_b.json`
(also listed in `files:`) was read only, not edited.

## Method

Dumped RK printed pages 344-355 (the whole SKUPINA VI exam paper plus both halves of its
answer-key table) with `booktool.py page`, then rendered the same PDF pages (pdf index 338-349)
to PNG at matrix 3x-6x and viewed every one — this PDF's line art is ~950 one-pixel inline
images invisible to `get_images()`/`get_drawings()`, and the OCR text layer mangles Greek
letters, degree/Ω symbols, and multi-part options. Every one of the 30 questions' options was
checked word-for-word against the rendered image, not the packet's OCR'd `question`/`options`
or its `current_cite`/`current_explanation`. All 30 HRS answer letters were additionally
cross-checked against the "ODGOVORI NA PITANJA" table (tiskana str. 354-355, rendered at 6x,
rows 1-60, column "Skupina VI") — all 30 match exactly, same finding as P3-0026's odd half.

Supporting theory citations were pulled by locating the matching RK chapter via
`booktool.py toc`/`find` and reading the actual page text — e.g. p.23-24 for the power formula,
p.62 for capacitor reactance, p.84-85 for the common-collector/emitter-follower section
(verbatim: "Pojačanje emiterskoga sljedila uvijek je manje od jedan, a ulazni i izlazni signali
su istofazni" — matches bk-teh-6-08's answer word for word), p.110-111 for series-RLC resonance
(Z=R), p.139 for the Π-filter and heatsink/ventilator sections, p.148-149 for the antenna
radiation-lobe rule, p.168 for the critical-frequency definition (near-verbatim match to the
question stem), p.172 for the 4/3-earth-radius radiohorizont rule, p.184-185 for the dip-metar
section, p.192 for the notch-filter rule ("postavlja se samo u slučaju kad postoji uočen problem
samo s jednom harmoničkom frekvencijom" — verbatim match to bk-teh-6-58), p.197 for parasitic
self-oscillation at "potpuno nepredviđenim frekvencijama" (verbatim match to bk-teh-6-52), p.198
for the receiver-sensitivity/blocking passage (verbatim match to bk-teh-6-54), and p.207
Tablica 10.2 for the exact 11,2 V/m field-strength limit at 10-400 MHz (bk-teh-6-60).

After every citation was drafted, every `cite.loc` printed-page number was re-verified
programmatically against `booktool.load('RK')`'s folio map — 0 bad pages across all 30 notes'
citations (script run, not just eyeballed).

## Defects that change what the option text actually says (not just the letter)

- **bk-teh-6-04**: packet options (a) and (c) are OCR-destroyed fractions with π: real page has
  (a) "5/π kΩ" (≈1,59 kΩ) and (c) "10/π kΩ" (≈3,18 kΩ); packet has (a)="> kQ" and (c)="ko" —
  strings carrying no numeric information at all. The packet's `answer`="a" is still the
  physically correct letter (Xc=1/(2π·50·2µF)≈1592Ω≈5/π kΩ), but option (a)'s own text in the
  packet is meaningless without the page.
- **bk-teh-6-14**: packet options are OCR-mangled λ (lambda) symbols: real (a)="λ", (b)="λ/2",
  (c)="3λ/2", (d)="4λ/2"; packet has (a)="%", (b)="a2", (c)="34/2", (d)="43/2". Again the
  `answer`="a" letter is correct but the attached text is unreadable without the page.
- **bk-teh-6-34**: the question stem itself is corrupted: packet has "[1-filtar se nalazi:";
  the real symbol is Greek Π (capital pi) — confirmed directly by the book's own prose on
  p.139, which spells it out as "II-filtar (PI-filtar)". Minor (doesn't affect the answer),
  but worth recording since "[1-filtar" alone is not decodable.

All three are written up with the full, page-verified text in the note; none of the packet's
`answer` letters were touched (rule 1) — only the prose describing what those letters mean, and
none were "fixed" in the packet file itself (out of scope; packet was read-only).

## Two questions with inferred (not book-verbatim) reasoning

- **bk-teh-6-18** (deviation-control block diagram): the book never states this exact
  clipper→pot→LPF→oscillator circuit is "for deviation control" in so many words. The note
  draws the conclusion from the figure itself (confirmed the arrow reads "K oscilatoru", ruling
  out phase-modulation-on-a-later-stage per p.141's explicit "ne izvodi djelovanjem na sam
  oscilator" for phase modulators) plus the general varicap/reactance-modulator description on
  p.139-140, and says so explicitly in the note rather than presenting it as a quote.
- **bk-teh-6-48** (dense-neighborhood antenna placement): no explicit book sentence recommends
  "antenna as far from neighbors as possible" for this scenario; the note infers it from the
  general distance/field-strength relationship shown in Sl. 9.2.6 (p.198-199) and says so.
- **bk-teh-6-44** (ppm→Hz conversion): pure arithmetic (21 MHz × 100 ppm = 2,1 kHz); no RK
  sentence covers unit conversion of ppm, so only the exam page is cited, consistent with how
  P3-0026 handled the analogous bk-teh-6-43.
