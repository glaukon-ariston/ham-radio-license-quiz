# P2-0061: Create GitHub repo and origin remote so the quiz feedback button works

## What was done

1. Installed GitHub CLI (`winget install --id GitHub.cli`) — not present in the environment
   at all beforehand.
2. Authenticated interactively as `glaukon-ariston` (`gh auth login`, browser device flow —
   done by Glaukon, not automatable).
3. Created a **public** GitHub repo: `gh repo create ham-radio-license-quiz --public
   --description "Croatian A-class HAM radio license exam quiz"` →
   `https://github.com/glaukon-ariston/ham-radio-license-quiz`. Public because
   `PUBLISHING.md` frames this project as a publicly distributed GitHub Pages link.
4. `git remote add origin git@github.com:glaukon-ariston/ham-radio-license-quiz.git` (SSH,
   matching `PUBLISHING.md`'s example commands). No push performed — this item's scope was
   the remote and build-time wiring, not publishing content. `PUBLISHING.md`'s one-time
   `gh-pages` setup is still a separate, not-yet-done step.
5. Created the `quiz-feedback` label on the new repo (`gh label create quiz-feedback -R
   glaukon-ariston/ham-radio-license-quiz --color FBCA04`) — required because GitHub silently
   drops unknown label names from the issue-URL `labels=` param, per the 0060 report.
6. Reran `python quiz/build/build_quiz.py` (not full `rebuild.py` — no notes/bank/book
   files touched, no need to reparse PDFs). Output confirms
   `repo=glaukon-ariston/ham-radio-license-quiz`; `quiz.html` now contains
   `const REPO = "glaukon-ariston/ham-radio-license-quiz";` and `REPORT_ENABLED = !!REPO`
   evaluates true, so `#reportBtn` is no longer hidden.
