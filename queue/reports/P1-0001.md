# P1-0001 — Make rebuild.py write relative to its own checkout

status: done

## What was wrong

Two scripts carried the same literal:

    DST = Path(r"g:/My Drive/Electronics/HAM Radio License/quiz")

in `quiz/build/rebuild.py:13` and `quiz/build/build_quiz.py:5`. Every build, from anywhere,
wrote `questions.json` and `quiz.html` back into the main Drive checkout. A build run in a
worktree would therefore overwrite the main tree's deliverables with its own branch's
content and leave no trace that it had — the files are gitignored, so `git status` in
neither tree would say a word about it.

## The change

Both now derive `DST` from the script's own location. The build directory is
`<checkout>/quiz/build`, so the quiz directory is one level up:

- `rebuild.py`: `HERE = Path(__file__).resolve().parent`, `DST = HERE.parent`.
  `HERE` gained `.resolve()`; it was already used for the subprocess `cwd`, for reading
  `bank.json` / `book_parsed2.json` / the two figure indexes, and for globbing `notes_*.json`,
  and resolving it makes all of those independent of the caller's cwd too.
- `build_quiz.py`: `DST = Path(__file__).resolve().parent.parent`. It had no `HERE` of its
  own — it is normally invoked by `rebuild.py` with `cwd=quiz/build`, but it is also runnable
  directly, and a relative path would have made "directly" mean "from quiz/build only".

Each script resolves independently rather than `rebuild.py` passing a path down. That keeps
`build_quiz.py` standalone, and both answers are the same by construction since both files
live in the same directory.

This matches the convention the rest of the build already uses: `figures2.py`, `strict.py`,
`check_notes.py`, `link_check.py` and `make_packets.py` all anchor on `Path(__file__).parent`
already, and `make_packets.py` already reaches the quiz dir as `HERE.parent`.

## What was deliberately not changed

Per the item's **Avoid**, the source-PDF paths stay absolute. `docs/` is shared across all
checkouts and is not part of any worktree's working set:

- `parse2.py:10`   `DOCS = Path(r"g:/.../docs")`
- `parse_book2.py:14`, `book_figures.py:19`  `Radiokomunikacije_ocr.pdf`
- `booktool.py:18`  `DOCS`

The worktree build below proves this is the right split: it read the PDFs off Drive and
wrote its outputs locally.
