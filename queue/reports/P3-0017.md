# P3-0017 — Book notes, skupina III propisi

## Scope

Wrote `quiz/build/notes_book_s3_propisi.json`: one teaching note per id in
`quiz/build/work/packet_book_s3_propisi.json` (20 ids, `bk-pro-3-01` through `bk-pro-3-20`, the
whole propisi packet for skupina III — no subject re-cut applied). Same `{note, formula?,
cite, flag?}` shape as the sibling `notes_book_s2_propisi.json`. No `links` key, matching the
established book-notes convention (`link_check.py`/`check_notes.py` only glob
`notes_zzz_expanded_*`). `packet_book_s3_propisi.json` (also in `files:`) was read only, not
edited.

## Method

1. Rendered/dumped printed RK pages 363–366 with `booktool.py page RK N` and compared every
   option letter and text against the packet/`questions.json` for all 20 ids — all match the
   print exactly (unlike bk-teh-3-36 in P3-0015, no scrambled options found here).
2. For every legal claim, pulled the actual NN150/22 article text (this PDF has no printed
   pagination, cited by članak/stavak/točka) and the actual RK descriptive-chapter text with
   `booktool.py page`/`find`, and confirmed each cited number/threshold word-for-word before
   writing it into a note — never trusted a "plausible neighbourhood."
3. Cross-checked the 6 ids that repeat facts already covered in `notes_book_s2_propisi.json`
   (14/15/16/17/18/20 here vs. pro-2-12/2-14/2-16/2-17/2-18/2-20 there) against that file for
   consistency, but re-pulled every article and page independently for this item rather than
   copying.

## Main finding: packet's `hrs_source` page numbers are off by one, same bug as P3-0016's predecessor

Every `hrs_source` in `packet_book_s3_propisi.json` is one printed page too low. Verified by
dumping RK printed 363, 364, 365, 366 directly:

- printed **363** is still the tail of **SKUPINA II** (its own questions 14–20) — not skupina
  III at all.
- **"SKUPINA III."** heading and its question 1 actually start on printed **364**, which holds
  q1–q7 (packet claims str. 363 for q1–7).
- printed **365** holds q8–q14 (packet claims str. 364 for these).
- printed **366** holds q15–q20 (packet claims str. 365 for these).

Not fixed in the packet (out of this item's `files:`); every `cite` in the notes file uses the
page verified live (364/365/366 per the three-way split above), not the packet's own
`hrs_source`. Given the compound-citation warning for this series, each of the three page
boundaries (364/365/366) was individually confirmed by reading that exact printed page's
content, not inferred from one page and assumed for the rest.

## Currency flags (7 of 20, `flag: "check"`)

Per rule 1, no HRS/RK answer was changed. Flagged where current NN150/22 diverges from the
RK/HRS key, or where the exact modern legal citation could not be independently confirmed
(mirrors `notes_book_s2_propisi.json`'s pattern):

- **bk-pro-3-02**: RK/exam says P-razred PEP ≤ 75 W; current NN150/22 Dodatak 1 t.2.2.1 sets
  it at 100 W (A razred also rose 1000→1500 W).
- **bk-pro-3-07**: RK/exam says "dva tjedna" (verbatim RK str. 233 text) to report a licence
  data change; current NN150/22 čl. 12 st. 16 sets 15 dana, not exactly the same.
- **bk-pro-3-01, -03, -13**: inspection-service powers/penalties trace to the old Zakon o
  telekomunikacijama (RK 3.2/3.2.1); ZEK (NN 76/22, not in `docs/`) is presumably the modern
  successor but its exact article wasn't available to verify, so none is cited (rule 5).
- **bk-pro-3-04**: NN150/22 čl. 20 st. 1 t. 5's "lokaciju ... s kojom je uspostavljena
  komunikacija" is grammatically ambiguous — could read as the correspondent's location rather
  than the operator's own — flagged and explained rather than asserted with false confidence.
- **bk-pro-3-20**: same as s2_propisi's pro-2-20 — RK's own "5 godina" text has no matching
  duration figure in current NN150/22 (which only requires the licence to *state* a validity
  period, not what it is).

Two power-limit questions (bk-pro-3-06 repeater ERP 15 W, bk-pro-3-19 beacon ERP 50/10/1 W)
were verified to **still match current NN150/22 Dodatak 1** exactly — no flag, unlike the
P-razred PEP figure.
