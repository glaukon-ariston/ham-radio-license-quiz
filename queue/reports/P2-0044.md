## The toggle

A `<select id="srcSel">` next to the existing theme selector in the sticky header (`header.bar`),
persisted to `localStorage` (`9a-ispit-src`) exactly like the palette selector. Two options,
labelled with live counts computed from `DATA.q` at load (`"Samo HRS lista (456)"` /
`"HRS + priručnik (1176)"`) so the numbers can't drift from the corpus.

`poolQs()` — `DATA.q.filter(q => srcPool==="all" || q.src==="hrs")` — is the single choke
point, ANDed into every existing section/cjelina filter:
- `sectionGroups(k)`, `home()`'s two tables, `buildPicker()`'s counts and per-section/per-cjelina
  "Vježbaj" filters, and the `data-sub` click handlers in `home()`'s subtable.
- Exam sampling in `start("exam")`: was hardcoded `q.src==="hrs"`, now `poolQs()`. `SEC[k].n`
  (40/20/20), `PASS=70`, and the per-area pass/fail logic in `finish()` are untouched — per the
  item's "Avoid," only which pool each section's 40/20/20 is sampled from changes.
- The exam-start confirm dialog text now names the active pool ("izvor: HRS + priručnik" /
  "izvor: samo HRS lista"), since the confirm screen is functionally the exam's start screen and
  the header selector sits behind (non-interactive) the confirm overlay while it's open — the
  choice has to be visible/settable *before* opening it, and the confirm text is what surfaces
  the current setting.

Left the existing "Sve iz HRS lista" (456) / "Dodatna iz priručnika" (720) picker entries
alone — those are pre-existing whole-corpus, cross-section shortcuts, orthogonal to the new
pool toggle which layers on top of section/cjelina choices instead of replacing them.
