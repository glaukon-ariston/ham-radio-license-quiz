# P3-0015 — Book notes, skupina III tehnički (b)

## Scope

Wrote `quiz/build/notes_book_s3_tehnicki_b.json`: one teaching note per id in
`quiz/build/work/packet_book_s3_tehnicki_b.json` (30 ids, `bk-teh-3-02` through `bk-teh-3-60`,
even numbers only — the second half of skupina III's tehnički section; the odd-numbered `_a`
packet was already done by P3-0014). Same simple `{note, formula?, cite, flag?}` shape as the
sibling `_a` file. No `links` key — `link_check.py`/`check_notes.py` only glob
`notes_zzz_expanded_*`, so no links were added rather than adding unverifiable ones.
`packet_book_s3_tehnicki_b.json` (also in `files:`) was read only, not edited.

## Method

The packet's own `current_cite` for all 30 questions is just
`"tablica ODGOVORI NA PITANJA, redak N, stupac Skupina III"` — the answer-key table location,
not a content citation — so every citation was built from scratch. For all 30 ids I:

1. Rendered the actual printed pages (309-320) as pixmaps with PyMuPDF and read them as images,
   not just OCR text, since this book's line art is ~950 one-pixel inline images invisible to
   `get_images()`/`get_drawings()`. Cropped a high-res close-up of the oscilloscope grid
   (bk-teh-3-42) to count divisions precisely rather than estimate from the full page.
2. Compared every option's exact text against the raw page render for all 30 ids — no scrambling
   found except one (below).
3. Found the specific book section/formula/worked example each question is drawn from with
   `booktool.py find`/`page`, and confirmed the citation's text actually produces the HRS-marked
   answer (verbatim quote or computation), not just a plausible nearby topic. Several questions
   (bk-teh-3-40, -50, -52, -54, -56, -58, -60) turned out to be near-verbatim lifts from specific
   RK paragraphs, which made verification unusually strong for this packet.
4. **Rendered and read the tiskana tablica ODGOVORI NA PITANJA itself** (str. 354-355, stupac
   Skupina III) as an image and cross-checked all 30 answer letters against it directly — not
   just trusting the packet's `answer` field. 29/30 matched; the one mismatch is the main finding
   below.

## Main finding: bk-teh-3-36 has scrambled options

The packet (and `questions.json`) stores `bk-teh-3-36` ("Kod FM odašiljača frekvencijska se
modulacija obično izvodi u:") as `answer: "a"`, `answer_text: "u MF pojačalu"`. Direct image
render of tiskana str. 315 shows the actual printed options are (a) "sklopu oscilatora",
(b) "u MF pojačalu", (c) "dvostrukom Π-filtru", (d) "izlaznom stupnju" — **(a) and (b) are
swapped in the packet relative to print**. The tiskana tablica ODGOVORI NA PITANJA (redak 36,
stupac Skupina III) marks letter **A** — the same letter the packet uses — but the *content*
the packet has filed under that letter is wrong: RK's own prose (5.3.8. Frekvencijski
modulator, str. 139-140) states verbatim that a varicap FM modulator sits "u krug
OSCILATORA", confirming the true printed option (a) "sklopu oscilatora" is correct, not
"u MF pojačalu". `questions.json`'s `bk-teh-3-36.options` differs from `book_parsed2.json`'s
extraction order for this one question only — an isolated ingestion defect, not a systematic
two-column parsing bug (verified: neighbouring two-column questions like bk-teh-3-35 are NOT
swapped). Per rule 1, I did not fix the packet or `questions.json` (out of this item's
`files:` scope) — I wrote the note explaining the verified-correct content and added
`flag: "check"` with the full discrepancy spelled out in the note text, so a maintainer with
write access to the packet/build pipeline can decide whether to relabel the option or accept
the flag.

## Other notable finds

- **has_figure is wrong for 7 questions**, same pattern P3-0014 found in the `_a` packet:
  bk-teh-3-06, -10, -16, -18, -20, -42, -44 all carry a real figure central to the question
  (Colpitts oscillator, AM/FM modulator circuits, PLL block diagram, envelope detector,
  oscilloscope trace, resistance-bridge schematic) despite `has_figure: false` in the packet.
  All 7 match `book_overrides.json`'s own figure-crop list exactly, cross-checked against the
  crops already in `quiz/build/figs_book/`. bk-teh-3-48, -52, -54 reference an *adjacent*
  question's figure conceptually (cross-reference style, like `_a`'s bk-teh-3-43) but carry no
  drawn figure of their own on their own page — treated consistently with the `_a` packet's
  precedent for that pattern.
- **bk-teh-3-50/-52 come from the same book paragraph** (str. 193, "4. Antenski prilagodnik —
  AP"), which literally states the 14 MHz / 30 MHz-cutoff-LPF/AP scenario used across both
  questions — a rare case where one paragraph is the source for two consecutive exam questions.
- **bk-teh-3-54 reuses bk-teh-3-53's UHF filter figure** (already covered by `_a`); verified via
  the 5×144 MHz = 720 MHz > 470 MHz arithmetic that the filter passes rather than blocks the
  5th harmonic, matching the HRS answer.
- No HRS-vs-current-law conflicts in this packet — pure electronics/RF theory, not
  propisi/pravila, so the currency-audit flag vocabulary doesn't otherwise apply here.
