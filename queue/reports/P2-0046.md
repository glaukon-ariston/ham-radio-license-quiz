# P2-0046 — Trim stray diagram labels from teh-137 option d

## What was wrong

`teh-137` (HRS-A, RA_ispiti_9_A_razred_Tehnicki_dio.pdf, pitanje 137, str. 19) option d)
in `bank.json` read:

    "PLL sintezator. Δf fref f0 = fref fazni NPF VCO detektor PLL programibilni djeljitalj"

The correct answer text ("PLL sintezator.") was followed by OCR-scraped labels from the
block diagram (sl. 3.6.4., RK 3.6.2., tiskana str. 126-127) that sits below question 137's
options — the same bug pattern already patched for `teh-186`, `teh-258`, `teh-046`,
`teh-112` and `teh-277` in `overrides.json`.

## Verification against the source PDF

Rendered `docs/RA_ispiti_9_A_razred_Tehnicki_dio.pdf` pdf-index 18 directly with PyMuPDF
(`get_text()`), which carries the printed folio "19" in its own margin — confirming this is
printed str. 19 as the item states, without relying on booktool.py (booktool.py only maps
the two priručnici, not the ispiti question banks; no page-mapping tool exists for this PDF,
so the offset was verified by reading the folio printed on the page itself).

The extracted text for question 137 is:

    137.
    Što prikazuje slika?
    a) Direktni digitalni sintezator,
    b) heterodinski oscilator,
    c) SSB predajnik,
    d) PLL sintezator.

    f
    fref                    f0 = fref

    PLL

    138.
    Susjedni kanal je: ...

    fazni
    detektor
    NPF
    VCO
    programibilni
    djeljitalj

This confirms option d) is exactly "PLL sintezator." (trailing period, matching the
convention already used for the last option elsewhere in bank.json, e.g. teh-138's own
option d "kanal na kojemu je moguće istodobno primati i odašiljati." — options a-c in a
question lose their trailing comma, the terminal option keeps its period). The diagram
labels ("Δf"/"f", "fref", "f0 = fref", "PLL", "fazni detektor", "NPF", "VCO", "programibilni
djeljitalj") are scattered figure captions from the PLL block diagram between q137 and q138,
not part of any option — consistent with the "PrimoPDF one-pixel inline images" trap noted
in BRIEF.md (get_images()/get_drawings() see nothing on this page; the labels only show up
as loose text blocks in get_text()).
