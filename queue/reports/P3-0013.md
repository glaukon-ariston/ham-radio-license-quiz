# P3-0013 — Book notes, skupina II propisi

## Scope

Wrote `quiz/build/notes_book_s2_propisi.json`: one teaching note per id in
`quiz/build/work/packet_book_s2_propisi.json` (all 20 ids, `bk-pro-2-01`..`bk-pro-2-20` — the
only packet for this section/skupina, so no `_a`/`_b` split). Same simple `{note, formula?,
cite, flag?}` shape as the earlier `notes_book_s1/s2_tehnicki_*.json` files; no links section
(neither `link_check.py` nor `check_notes.py` process this file's naming pattern).

## Why this item got the citation-verification treatment seriously

Three earlier items in this exact notes-writing series — P3-0008 (skupina-1-pravila),
P3-0009 (skupina-1-propisi), P3-0012 (skupina-2-pravila) — were all blocked for the same
failure: a citation topically adjacent to a claim but not actually backing it (wrong article,
wrong number, or the note's own prose citing a different page than its `cite` field). Given
this is the fourth propisi/pravila item in the series, I treated every citation as requiring
independent, word-for-word verification against the source PDF, not reuse of a plausible
citation.

## What I found before writing anything

This packet turns out to be the exact same mock-exam paper (RK's own printed "zbirka ispitnih
pitanja", SKUPINA II) whose underlying facts largely overlap ones already audited for the
456-question HRS bank (`notes_zzz_expanded_propisi_a/b.json`, `pro-XXX` ids). I read that prior
work first (not to copy citations, but to know where the corpus's currency audit had already
found HRS-key-vs-current-law divergences), then independently pulled and read the actual
`NN150/22` article text and the actual RK printed pages for all 20 questions with
`booktool.py`/pymupdf — not trusting the packet's own `current_cite` (which for every question
in this packet is just `"tablica ODGOVORI NA PITANJA"`, i.e. the answer-key table location, not
a real content citation) and not trusting the packet's `hrs_source` page numbers either (see
finding below — they're wrong).

**Packet's own `hrs_source` printed-page numbers are off by one for the whole packet.**
Verified live with `booktool.py page RK <n>`: SKUPINA II starts on printed **str. 361**
("SKUPINA II. 1. Podaci se u dnevnik..."), continues onto **str. 362** (items ~10–16), and
**str. 363** (items ~14–20 by the book's own — partly reconstructed — numbering). The packet's
`hrs_source` field claims str. 360 for q1–6, str. 361 for q7–13, str. 362 for q14–20 — each one
page early. I did not fix `make_packets.py` (out of this item's `files:`, and P3-0006 already
flagged that regenerator work as its own future item) — I just did not reuse the packet's page
numbers in my `cite` fields, and verified every page I did cite directly.

**Six real HRS-key-vs-current-NN150/22 divergences, all independently confirmed from the
source PDF, not inferred from the prior HRS-bank audit:**
- `bk-pro-2-01`/`-08` (pencil forbidden in the logbook) — `NN150/22` čl. 20. st. 1. requires
  only "čitljiv zapis" (legible record); the "cannot be erased" language that bans pencil is
  RK's own older description (str. 242), not in the current Pravilnik's text.
- `bk-pro-2-02` (blank line forbidden) — confirmed absent from both `NN150/22` čl. 20. and RK's
  own descriptive text (str. 242–243); only exists in the exam-question corpus itself.
- `bk-pro-2-04` (12 years minimum age to sit the exam) — `NN150/22` čl. 9. sets **no** age
  floor at all (only requires parental consent under 18); "12 godina" is RK's 2005-era text
  (str. 232).
- `bk-pro-2-05` (report a second fixed location after **four weeks**) — `NN150/22` čl. 13. st.
  2. sets **90 days (≈ three months)**, not four weeks; RK's own printed page offers *both*
  thresholds as separate options (c=three months, d=four weeks) and the key marks the old one.
- `bk-pro-2-06` ("communicate with stations that have no license") — RK's own older text (str.
  242, item 4) uses exactly that phrase, but current `NN150/22` čl. 18. t. 4. rewrote the
  criterion to be about a station lacking a *valid identification mark*, not license status.
- `bk-pro-2-13` (P-class exam includes Morse code) — directly contradicted by RK's **own** text
  two chapters earlier (str. 246: "NIJE OBVEZAN DIO ISPITA" — voluntary for both A and P) *and*
  by the official `Obvezni_dio_ispitnog_programa.pdf`, whose P-razred operational content list
  (phonetic alphabet, Q-code, abbreviations, callsigns) has no Morse-code line item.

Two more got a `check` flag for a citation I could confirm but couldn't fully close:
`bk-pro-2-11` (inspection-service power to suspend activity "three months to a year") is
word-for-word real — but only in RK's own text (str. 230), attributed to the now-repealed old
Zakon o telekomunikacijama; the current legal basis would be ZEK NN 76/22, but I could not
confirm which article, so — per the corpus's own established convention for this exact same
gap on the HRS-bank side (`pro-088`/`pro-091`) — I cited ZEK only generically and said so,
rather than inventing an article number. `bk-pro-2-20` (license valid for 5 years) is
word-for-word real in RK (str. 229) but `NN150/22` itself never states the duration (only that
the license record one); flagged the same way.

Per rule 1, none of this changed any HRS/RK-marked answer — all 9 flagged questions keep their
original marked letter; I only added `flag: "check"` plus an honest, sourced explanation of
the gap, matching the flag vocabulary (`check`/`conflict`) already established across the
propisi corpus's currency audit.

**Two "no flag needed" checks worth naming**: `bk-pro-2-14` (self-built station needs an
HRS-issued certificate) uses the exam's "potvrda o tehničkoj ispravnosti", while `NN150/22` čl.
12. st. 3. actually says "uvjerenje o tehničkoj sukladnosti" — same requirement, different
wording, noted in the note text but not flagged since the substance is confirmed correct.
`bk-pro-2-07` (40 dB spurious-emission limit, phrased with a ">25 W" qualifier) — the
`NN150/22` čl. 22. st. 4. table has no power split for the <30 MHz band (only the higher bands
split by 25 W), so 40 dB is correct regardless of the stated power; noted, not flagged.
