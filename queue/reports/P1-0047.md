# P1-0047 — book notes never reach the live quiz (byid excludes extra in rebuild.py)

## What was wrong

`quiz/build/rebuild.py:111` built `byid = {q["id"]: q for q in hrs}` — HRS bank only. The
"attach explanations" loop right below looks every note id up in `byid`, so every
`bk-*` id from any `notes_book_*.json` file missed and was pushed onto the `unknown` list
(silently, since `unknown` was only printed, never failed the build). Confirmed before the
fix: `explained=456` (HRS only), and `unknown` contained all `bk-*` note ids, e.g.
`bk-teh-2-15`, `bk-pro-1-19`, `bk-teh-4-19` — the ones Glaukon named.

## Fix

Two spots, both required to make the fix actually observable in the build summary (not just
silently correct internally):

1. Line 111: `byid = {q["id"]: q for q in hrs + extra}` — `extra` is already fully built
   (with citations, figures, subsections) by this point (lines 89-108), so folding it in here
   is safe; nothing between `extra`'s construction and line 111 reads `byid`.
2. The `_meta` block (`tot`, `exp`, `explained`, `explained_by_section`) previously counted
   only `hrs`, so even with the `byid` fix the printed `explained` count would have stayed at
   456 and silently misreported the fix as doing nothing. Changed all four to iterate
   `hrs + extra`, matching the item's "Done when" (explained count must visibly rise).

Did **not** touch `_meta["flagged"]` — it still lists only `hrs` questions with a `flag`
(some `notes_book_*.json` files do set `flag`, e.g. in `notes_book_s1_propisi.json`,
`notes_book_s3_tehnicki_b.json`, etc.). This is a pre-existing, separate gap: the *per-question*
`q["flag"]` is correctly attached to `extra` questions now (the UI reads `q.flag` directly per
`quiz/build/build_quiz.py:13,556-558`, so flagged book questions DO show the warning banner in
the quiz — that part works). Only the end-of-build console summary list of flagged ids
undercounts by omitting book-sourced flags. Flagging this rather than fixing it, since it's
outside this item's one-line-shaped scope and "Done when" never mentions it.
